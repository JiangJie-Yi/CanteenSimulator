# 低面數做法手冊（Low-Poly）

店主定的鐵律（2026-11-02）與之後每次減面學到的做法，整理成一份。建模的總守則在 [`MODELING.md`](MODELING.md)（建任何模型前必讀），這份是其中「低面數」的細節。
規則本身也寫在 `CLAUDE.md`「3D 模型」；每件模型的細節在 `docs/DETAILS.md`（用搜尋找名字）。

## 一、鐵律（不能改）

1. **單一小物件 50～100 面**；圓的東西外圈 16～24 段（16 段輪廓會看出稜角時用 20）。造型複雜、要保住輪廓的才多一點。
2. **不從中心放射收聚**（一圈三角形擠在一點，光影會出黑斑）：封口用 `blender/common.py` 的 `ladder_fill`（一格一格的梯狀四邊形）；`export_dish` 匯出前會把凸的多邊形封口自動轉成梯狀。
3. **擺放先量邊界，不准穿模、不准兩個面在同一平面**：量 Box3／`bound_box` 留間距；貼在表面的東西抬高幾公釐或 `polygonOffset`。
4. **字不做成網格**：畫進貼圖。

## 二、先選做法：由便宜到貴

店主的方向：**乾淨的低面數形體（四邊形為主），細節全部進貼圖**（顏色、法線），不是很多面，也不是減面工具減出來的碎三角形。看得到的東西照「離鏡頭多近、從幾個角度看」挑最便宜的一種：

| 做法 | 幾面 | 什麼時候用 | 例子 |
|---|---|---|---|
| **一片貼圖**（四邊形 2 面，透明處用 alpha 切掉） | 2 | 只從前面看、或藏在櫃子裡、層架後排的東西 | 飲料櫃後排、碗盤櫃裡的碗疊（第 74 項）、遠處的瓶子 |
| **拍原本的樣子貼在一片上**（在 Blender 用正交相機拍原本的模型，背景透明，拼進一張圖） | 2～4 | 收在櫃子、抽屜裡，只從一兩個方向看的一疊東西 | 碗盤櫃的碗疊與湯匙（第 74 項：3,020 → 28 面） |
| **十字交叉薄片**（2～3 片，雙面、alphaTest） | 4～6 | 細碎的植物、毛邊、繩頭，從各角度都要有點厚度 | 柳樹葉、神棚供花（第 57 項）、菰樽的稻草末端（第 72 項） |
| **方塊／盒子＋貼圖**（四面或六面都貼圖） | 10～12 | 方的東西、或一整排並排的東西，從斜角也要看得出厚度 | 紙箱、酒箱裡的一排瓶子（瓶的輪廓畫在側面，透明切掉） |
| **假透視的平面**（一片，著色程式算視線穿進去碰到哪裡） | 2 | 門裡、窗外的空間：要有深度，又不想做出整個空間 | 上二樓的樓梯（見下面）、圓窗外的景色 |
| **低面數形體＋畫的貼圖＋法線貼圖** | 50～1,000 | 主角級的擺設，近看要有體積 | 菰樽（第 72 項）、小判、地瓜馬鈴薯 |
| **高模烘焙到低模**（顏色、法線、AO） | 依造型 | 雕刻感的東西，形狀複雜但輪廓簡單 | 招財貓、惠比壽（第 59 項）、地瓜（`bake_tubers`） |

### 假透視的平面怎麼做（上二樓的樓梯）

`DiningRoom.tsx` 的 `STAFF_STAIRS`（員工門後面）：門框裡只有**一片兩個三角形的平面**，自己的 `ShaderMaterial`。每個像素：

1. 從鏡頭的位置（`uCam`，換成這片平面自己的座標）拉一條線，穿過這個像素，往牆後面延伸。
2. 用數學算這條線先碰到樓梯間的哪個面：左右的牆、入口的地板、每一階的踏板與踢板（`stairY`：在這個深度第幾階、多高）、斜的天花板、平台後面的牆。
3. 照碰到的那個面上色：杉木腰板、灰泥、木紋；平台上紙燈的暖光、門口照進來的一點光；角落與階梯的折線壓暗，跟門框接的邊最暗。

所以從任何角度看，樓梯都在門後面「有深度」地往上，視差是對的（畫死的一張圖只有正面看才對），卻只花 2 個三角形、一次繪製。圓窗外的景色是同一個原理（多層圖疊出前後）。限制：只適合**看進去、不會走進去**的空間；形狀要能用簡單的數學描述（平面、盒子、階梯）。

## 三、貼圖怎麼畫

- 用 numpy 在 Blender 腳本裡畫（`common.py` 的 `fbm`、`smooth`、`mix`、`grid01`、`image`）；高度圖轉法線用 `to_normal`，遊戲裡要保留 `normalMap`（toon 材質也可以）。
- **字**：Blender 文字物件轉三角形，填進貼圖（2～4× 超取樣）。平面的用 `DecalAtlas`；曲面上的直接畫進那個面的貼圖（菰樽的 `Print`）。這台電腦只有 YuGothic，要粗的毛筆感用擴張（菰樽的 `brush`）。
- 一組相同的東西共用一張圖、一格一個（三個菰樽一張 2048×1536、一列一個），一個材質就一次繪製。
- 透明薄片的貼圖在遊戲裡：`alphaTest 0.5`、`DoubleSide`、**不做縮圖**（遠看細的東西才不會變禿）、不描線（`inkModel` 第二個參數跳過，不然整片的邊被描黑）、通常不投影。
- 不用 `transmission`（玻璃瓶用一般材質加畫的反光）。

## 四、做完的檢查（每次都要）

1. Blender 腳本印出三角面（例：`KOMODARU_TRIS`）；`node scripts/mesh-audit.mjs <模型>` 沒有問題。
2. 放進遊戲後 `node tests/e2e/clips.mjs` 看有沒有穿模。
3. **同一個鏡頭改前／改後近拍對照**：舊模型用 `git show HEAD:public/models/x.glb` 存成暫存檔，Playwright 的 `page.route` 換回來拍（需要舊程式時，暫時把 `git show HEAD:` 的那個 .tsx 換回去拍完再換回來，一律先寫暫存檔再 `mv`）。看得出變差就再改，不要交出去。
4. 回報：面數前後、檔案大小前後、場景總面數與繪製次數前後、對照圖的路徑。

## 五、試過不好的

- 減面工具（`blender/optimize_glb.py`）對有烘焙 UV 的模型會弄亂（惠比壽一片黑色碎片）；繩子會變扁、桶身出現接縫（舊的菰樽）。能從源頭重做就重做。
- 一堆一顆顆的東西（馬鈴薯堆）整堆烘到一個殼上：輪廓與縫不見了，像一塊麵包。要留真的一顆顆，或改用薄片。
- 平面畫死的一張景深圖：只有正面看才對（樓梯第一版），要有深度用假透視的平面。
