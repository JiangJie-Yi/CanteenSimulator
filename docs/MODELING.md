# 建模守則（建任何模型之前必讀）

店主定的（2026-11-13）：**建立或修改任何 3D 模型之前，先讀完這份**。三件事一起顧：**高品質、遊戲性、低面數**；並且**能用幾何形狀構成的，就用幾何形狀構成**。
低面數的各種做法與檢查細節在 [`docs/LOWPOLY.md`](LOWPOLY.md)；每件既有模型的紀錄在 `docs/DETAILS.md`（搜尋名字或檔名）。

## 一、三個原則

### 1. 高品質（近看要像真的）

- **先找參考**：店主給的照片、Sketchfab 預覽（只看圖，不下載）、真品的樣子。照參考的比例、配色、細節層次做，不憑印象。
- **貼圖要包得仔細**（店主說的：「貼圖包裝要仔細，才會好看」）。一張好貼圖有好幾層：
  - 底材：木紋、和紙纖維、草蓆的一列列、玻璃的厚薄與模具接縫。
  - 主體：大字、圖案，有大小對比。
  - 細節：小字欄、框線、印章、金箔點、英文拼音。
  - 舊化：磨損、污漬、邊緣壓暗。
- **字**：大字用毛筆字型 `blender/fonts/YujiBoku-Regular.ttf`（SIL OFL）；小字用 YuGothic。字一律畫進貼圖，不做成網格。
- **名稱**：酒名、商品名照真的命名方式自己創，上網查過沒有同名的真品才用（店主要的：不要亂取，也不要真的商標）。
- **假的立體會穿幫**：繩子、把手、凸起的邊這類有厚度、會被斜看的東西，用一點幾何讓它真的鼓起來，不只畫在平面上。菰樽的繩子就是先畫平的被店主指出，改成半圓的管子。

### 2. 遊戲性（放進店裡要能用、好用）

- **尺寸**：跟人物、吧台、行燈比例要對。放進遊戲前先量一件旁邊的東西當比例尺。
- **位置**：
  - 先量要放的地方（Box3、往下打射線看是哪個表面多高），留間距，不擋客人和員工的動線（`kitchenBlocks`、`paths.mjs`）。
  - 不擋客人看料理台的視線。
- **互動**：
  - 用 `<Movable id label>` 包起來，開發者模式能移動。
  - 名稱寫中文，日文、英文補在 `data/editText.ts`。
  - 要能指、能點的，給滑鼠提示（`setTip`）。合併過的模型沒有滑鼠事件，另外放一個看不見的感應方塊。
- **一眼認得**：從遊戲的一般視角（不只近拍）看得出是什麼。輪廓比細節重要。
- **會變的狀態**：例如烤熟變色、盤子變髒、庫存變少，改模型時要保留，改完實際跑一次流程確認。

### 3. 低面數（店主的鐵律）

- 單一小物件 50～100 面；圓的外圈 16～24 段；不從中心放射收聚（用 `ladder_fill`）；不穿模、不同平面。
- 做法由便宜到貴的選法（一片貼圖、十字薄片、方塊加貼圖、假透視平面、低模加畫的貼圖、烘焙），見 [`LOWPOLY.md`](LOWPOLY.md)。

## 二、能用幾何就用幾何

形體先用**簡單的幾何形狀組出來**，細節才交給貼圖：

| 形體 | 用什麼幾何 | 例子 |
|---|---|---|
| 圓的、轉出來的 | 車削（一條輪廓繞一圈，16～24 段，幾圈就夠） | 酒瓶、菰樽的桶身、花瓶、碗 |
| 有斷面的長條 | 擠出（一個 2D 斷面沿直線拉長） | 兩層的酒台、木框、門檻 |
| 方的 | 方塊（需要時倒一刀角） | 箱子、台座、腳 |
| 沿線走的 | 管子（4～6 邊；只看得到一半的用半圓 3 面） | 繩子、把手、電線 |
| 薄的、細碎的 | 一片或十字交叉的薄片＋透明貼圖 | 稻草末端、葉子、吊牌 |

原則：

- **輪廓用幾何，表面用貼圖**。輪廓（剪影、厚度、凸起）是幾何的事；顏色、紋路、字、小凹凸（法線貼圖）是貼圖的事。
- **組件少而準**：每個零件都要說得出存在的理由（輪廓、厚度、會動、會被點）。看不出差別的零件不要。
- 減面工具是最後手段：先想能不能從源頭用幾何重做（店主看過減面工具弄壞的惠比壽）。

## 三、流程（每一件都照做）

1. **讀**：這份、`LOWPOLY.md`；在 `docs/DETAILS.md` 搜尋它或它旁邊的東西。
2. **參考與計畫**：
   - 列出參考、形體由哪些幾何組成、面數預算、貼圖張數與內容、放在哪裡（檔案：行號、量到的座標）。
   - 重大的先給店主看。
3. **建**：`blender/<名字>.py` → `public/models/<名字>.glb`；印出三角面數；輸出 Blender 預覽圖。
4. **放進遊戲**：材質照 `LOWPOLY.md` 的設定（toon、透明薄片、法線貼圖保留、需要反光的用 standard 加 `reflectStudio`）；預設位置寫進 `edit.ts`。
5. **檢查**：
   - `node scripts/mesh-audit.mjs <模型>`、`node tests/e2e/clips.mjs`。
   - 遊戲裡同一鏡頭近拍與一般視角各一張；改舊模型要前後對照。
   - 量三角面與繪製次數的前後。
   - `npx tsc -b`、`npm test`；動到流程的跑 `npm run e2e`。
6. **記錄**：
   - `TASKS.md` 那一列寫結果與數字；`WORKLOG.md` 寫過程與試錯。
   - `docs/DETAILS.md` 寫做法與店主為什麼要這樣。

## 四、店主說過的（不要再犯）

- 貼圖太陽春、色塊加字就交：要有層次（見「高品質」）。
- 畫上去的繩子、繩圈被看出是平的：給一點幾何。
- 亂取酒名（例：把店名「聞野」當酒名）、用真的牌子（例：菊正宗）：都不行，照真品的命名方式自創並查過。
- 面數太多的地方：串上的切身、椅子、喇叭、碗盤櫃裡的杯碗、保溫桶。都改成幾何加貼圖（第 74～81 項）。
